# smol-site

The showcase for smol, a terminal home screen for Android with a local AI brain. Static, no build step: open `index.html`, or serve the folder.

Pages: `index` (overview), `souls` (Nyx, Mochi, Bit, live), `launcher` (four screens, live), `spec` (the shader and state reference the Android port reads), `story`.

The souls run the real shaders in WebGL; `spec/` holds the exact strings `assets/souls.js` runs.
